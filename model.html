What the model knows, and how we know.

A logistic-regression model over 13 features computed from one-minute candles. It estimates whether the +40% target is hit before the −20% stop within 60 minutes, charging 1.5% per side for fees and slippage. It ships with the page and runs in your browser; the live agent computes its inputs with the same code used in training.

Data and limits

  • One-minute candles from GeckoTerminal's free API, from pools that were trending or most-traded when collected, plus 54 fresh launches (239 samples) captured minutes after creation and resolved hours later, whatever happened to them. They're there to check that the trending pools aren't just survivors, and they're still a small sample.
  • One sample every five minutes along each pool's history, only where the agent would have looked (FDV $15K–$50M, $1.5K+ traded in 15 minutes, 5+ minutes old), capped per pool. Pools are split into train, validation and test so no pool appears in two.
  • Candles don't show who is trading. That's what the RugCheck safety gates and live order flow are for, and a trade needs both keys.
  • Memecoin behavior shifts quickly and this is a small, recent dataset. Simulated past returns are not a promise of future ones. The model is retrained from fresh data with two commands: node model/collect.mjs and npm run train.
